# hyprland-g8d

**🚧 В разработке · ALPHA · интерфейс, функции и установщик ещё меняются.**

Минималистичная оболочка на Hyprland: графитовый фон, настраиваемый акцент,
панель, меню по наведению, отдельное приложение настроек и собственная сессия входа.
Текущий предварительный выпуск — `v0.1.0-alpha.2`, не стабильная версия.

## Соседство с твоим Hyprland

Устанавливается отдельный пункт **hyprland-g8d** на экране входа.
Конфиги лежат в `~/.config/hyprland-g8d`, существующий `~/.config/hypr` не меняется.
Твоя обычная сессия Hyprland/KDE остаётся в списке. Автовход и менеджер входа не переключаются.

Это отдельная **конфигурация и сессия**, а не второй форк/бинарник композитора:
используется системный пакет Hyprland. Установка пакета или его обновление относится
ко всем сессиям. Конфиги g8d используют Lua API: проверялись на Hyprland 0.56 и 0.57;
для старого Hyprland с конфигурацией только `.conf` этот выпуск не подходит.

## Установка одной командой

Поддерживаемый автоматический установщик: **Arch Linux и CachyOS**.
Запускай из терминала **обычным пользователем**, без `sudo` перед всей командой:

```bash
curl -fsSL -o /tmp/g8d-bootstrap.sh https://raw.githubusercontent.com/G8Dman/hyprland-g8d/v0.1.0-alpha.2/bootstrap.sh && bash /tmp/g8d-bootstrap.sh
```

Нужны интернет, `curl`, `tar`, `bash` и доступ к `sudo`. Команда сохраняет скрипт во временный файл и запускает его через `bash`, поэтому она работает в `bash`, `zsh` и `fish`.
Установщик скачивает именно указанный alpha-релиз, запрашивает установку пакетов
через `pacman`, создаёт изолированное Python-окружение, проверяет Lua-конфиг
и добавляет пункт сессии. Текущий рабочий стол не перезапускается.
Перед установкой пакетов приведи систему в актуальное состояние обычным для тебя
способом; установщик не выполняет `pacman -Sy` и не отключает существующие сервисы.

Повторная установка делает локальную резервную копию g8d в
`~/.local/state/hyprland-g8d/install-backups/`. Настройки экранов, обоев, календаря
и эффектов сохраняются. Редактируемые файлы кода/темы обновляются, поэтому свои
правки в них предварительно сохрани. Личные аккаунты и настройки автора не распространяются.

Для просмотра установщика перед запуском или ручной установки:

```bash
git clone https://github.com/G8Dman/hyprland-g8d.git
cd hyprland-g8d
git checkout v0.1.0-alpha.2
bash install.sh --dry-run
bash install.sh
```

Варианты: `--no-packages` — зависимости уже есть; `--no-session` — без записи
системного пункта входа. Полный список пакетов: [packages.txt](packages.txt).
Установщик не предназначен для запуска от root. Другие дистрибутивы пока не проверены.

## Первый запуск

1. Сохрани работу и выйди из текущей графической сессии.
2. На экране входа выбери **hyprland-g8d**, затем введи свой обычный пароль.
3. Нажми **Win+Ctrl+S**: откроются настройки g8d.
4. В «Экраны» настрой разрешение, частоту, масштаб и координаты. Мониторы изначально
   определяются автоматически. Изменения нужно подтвердить за 15 секунд, иначе они отменяются.
5. Положи обои в `~/Изображения/wallpaper` и нажми **Win+W**.

Если менеджер входа уже был запущен во время установки, новая сессия может появиться
после обновления его списка или следующей загрузки системы. Из TTY доступен запуск
`~/.local/bin/hyprland-g8d`. Свою обычную сессию выбирай в том же списке, когда захочешь вернуться.

## Что есть

- Верхняя панель, системный трей и рабочие столы блоками по пять: 01–05, 06–10 и далее.
- Наведение на часы: календарь, мониторинг CPU/RAM/GPU и музыка — вкладки с анимацией.
- Правый верхний угол: профиль, яркость экранов, Wi-Fi/Bluetooth, игровой режим, эффект курсора и настройки.
- Меню по наведению скрываются поверх полноэкранных приложений на соответствующем мониторе.
- MPRIS-плееры, текущая композиция и управление воспроизведением, оформление винила.
- Разные обои на разных экранах; статичные изображения и GIF/видео **без звука**.
- Alt+Tab: быстро — два последних окна; удержание — меню выбора окна.
- Графическое приложение «Настройки g8d»: Wi-Fi, Bluetooth, экраны, звук, оформление,
  приложения по умолчанию и поиск по расширению файла.
- Игровой режим сокращает расход памяти компонентов оболочки. Он не обещает
  уменьшить память сторонних приложений/ядра и не гарантирует конкретный FPS.
- Вспышка с осколками на границе экранов; отключается в правом меню и в настройках.
- Блокировка с часами, индикаторами языка и Caps Lock.

### Название и обновления

Win+Ctrl+S → «Оформление» → «Название оболочки»: введи до 32 символов и нажми
«Сохранить название». Меняются панель, боковая подпись настроек и блокировка.
Имя сессии и пути остаются `hyprland-g8d`. Выбор хранится в `branding.json`
и сохраняется при обновлении и смене акцента. Системная тема SDDM на всех
пользователей этой настройкой не изменяется.

«О системе» → «Обновить оболочку» открывает окно обновления. Оно выбирает
последний опубликованный релиз, включая alpha, проверяет SHA256 архива и
вызывает установщик без sudo, без установки пакетов и регистрации сессии.
После обновления выйди и войди снова. Для старой локальной сборки без версии
обновление предложит текущий релиз. Личные правки кода предварительно сохрани.
Системный Hyprland эта кнопка не обновляет: обновляй его обычным полным
обновлением дистрибутива. Кнопка «Обновить данные» в шапке лишь перечитывает
состояние устройств.

### Обои, календарь и приложения

**Обои:** Win+W → действие → экран → файл. Акцент можно выбрать отдельно или получить
из изображения. Анимированные обои могут расходовать GPU/RAM; игровой режим их приостанавливает.

**Календарь:** наведи на часы → «Календарь» → ⚙ → вставь закрытый iCal-адрес
из настроек собственного Google Календаря. Это подписка **только для просмотра**,
обновление раз в 5 минут. Приватную ссылку не публикуй; аккаунт автора не включён.
Без подключения остаётся обычный календарь. Копия событий доступна офлайн после синхронизации.

**Приложения:** Win+Ctrl+S → «Приложения» → введи `pdf`, `.mp4`, `docx` или `tar.gz`.
Появится текущая программа и выбор другой. Известные форматы могут иметь общий MIME-тип
(например, JPG/JPEG), а неизвестное расширение получает отдельную ассоциацию.
Настройки приложений, сети, Bluetooth и звука общие для текущего пользователя/компьютера,
а не отдельные копии внутри g8d.

**Музыка:** обычное управление работает через MPRIS без аккаунта. Кнопки Яндекс Музыки
экспериментальные: требуют отдельно установленного и настроенного `yamusic-cli` с пользовательским
сервисом `g8d-yamusic.service`. Он не скачивается и не авторизуется установщиком.
Без него используй любой MPRIS-плеер. Codex-интеграция из личной сборки автора не включена.

## Тема экрана входа — необязательно

В [extras/sddm/g8d](extras/sddm/g8d) есть минималистичная тема SDDM в стиле блокировки.
Если SDDM уже используется:

```bash
sudo pacman -S --needed sddm qt6-virtualkeyboard
sudo bash scripts/install-sddm-theme.sh
```

Команда устанавливает только тему, сохраняет предыдущую и ничего не перезапускает.
Она не переключает Plasma Login/GDM на SDDM, не меняет PAM и не исправляет автоматически
проблемы драйверов/клавиатуры. Если нужна смена менеджера входа, делай её отдельно
из TTY после завершения графических сессий.

## Ограничения alpha и диагностика

Это перенос личной сборки в публичный проект. Полный вход на произвольном оборудовании,
все NVIDIA/HiDPI-конфигурации и другие дистрибутивы не проверены. Автоустановка не обещает
изолировать версии системных пакетов. Не запускай установку, если не готов разбираться с alpha-сборкой.

- DDC/CI-яркость зависит от поддержки монитора, включённого DDC/CI и прав доступа к I²C;
  отсутствие датчика не равно 0%. Встроенная подсветка использует `brightnessctl`.
- Настройки сети требуют работающего NetworkManager, Bluetooth — BlueZ. Установщик
  не включает их автоматически, чтобы не конфликтовать с твоей сетью/менеджером.
- Не все приложения публикуют значок в трее или MPRIS-интерфейс.
- Логи: `~/.local/state/hyprland-g8d/`, прежде всего `autostart.log` и `wallpaper.log`.
- Проверка: `Hyprland --verify-config --config ~/.config/hyprland-g8d/hyprland.lua`.
- Если сессия не запускается, выбери прежнюю сессию или перейди в TTY через Ctrl+Alt+F3.
- Для отчёта приложи версию Hyprland, дистрибутив и очищенный фрагмент логов.
  Не присылай пароли, OAuth-токены, приватные ссылки календаря и полные конфиги аккаунтов.

## Обновление и удаление

Для обновления клонированной версии: выбери следующий опубликованный тег и снова запусти
`bash install.sh`. Перед обновлением читай заметки выпуска. Установка не делает `git pull`
и не меняет автоматически каналы на нестабильный `main`.

```bash
bash uninstall.sh --yes
```

Удаляются только запускающие файлы g8d и общий пункт сессии; конфиги, обои, резервные копии
и системные пакеты остаются. Обычный Hyprland/KDE и менеджер входа сохраняются.
Общий пункт входа используется всеми пользователями, установившими g8d на этом ПК.
