Super + T / Enter     Терминал
Super + R / D         Приложения
Super + Ctrl + S      Настройки g8d
Super + W             Обои и акцентный цвет
Super + E             Файлы
Super + B             Zen Browser
Super + Q             Закрыть окно
Ctrl + Alt + Esc      Завершить приложение кликом по окну (Esc — отмена)
Super + F             Полный экран
Super + V             Плавающее окно
Super + J             Поменять разделение
Super + стрелки       Фокус
Super + Shift + стрелки  Переместить окно
Super + 1…0           Рабочие столы 1…10
Super + Shift + 1…0   Перенести окно
Super + S             Скрытый рабочий стол
Super + Shift + V     Отправить окно на скрытый стол
Super + Space         RU / EN
Super + мышь          Переместить / изменить размер
Print                 Снимок области → файл + буфер
Super + Shift + S     Снимок области
Super + L             Блокировка
Super + Escape        Меню сессии
Super + F1            Эта памятка (q — закрыть)
