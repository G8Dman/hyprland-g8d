# Nothing

Interface style: OLED black / paper white, Space Grotesk body, Space Mono data, Doto clock and CPU readout.
The independent taskbar styles remain Graphite and Clear. No runtime network access is needed.

Fonts are bundled from https://github.com/google/fonts under each family's SIL Open Font License (see fonts/*/OFL.txt).
Design workflow: https://github.com/dominikmartn/nothing-design-skill.
Native layout: plugins/nothing.css; semantic palettes and config rendering: plugins/ui_themes.py.
