# Проверки alpha.1

Дата подготовки: 14 ноября 2026. Хост: CachyOS, Hyprland 0.57, Python 3.14.

- Разбор Python, проверка shell-синтаксиса и JSON.
- Аудит дерева поставки: нет приватной ссылки календаря, аккаунтов, токенов,
  домашнего пути автора, IP-адресов, резервных копий и схемы его мониторов.
- Реальный запуск установщика в отдельную тестовую домашнюю папку с
  `--no-packages --no-session`: создание Python venv, загрузка зависимостей,
  импорт GTK/Layer Shell, установка файлов и desktop entry.
- Конфигурация принимается `Hyprland --verify-config`.
- Повторная установка: сохранены существующий Hyprland, пользовательские настройки
  календаря, мониторов, акцента и эффектов; резервная копия создана.
- Вложенный запуск публичной конфигурации через `start-hyprland` с Wayland-бэкендом:
  обои, Waybar, hover-триггеры и GTK dashboard появились; ошибок конфигурации нет.
  Тестовая сессия завершена отдельно от рабочего стола пользователя.

Оболочка разработана и использовалась на личном компьютере автора. Это не равно
проверке публичного установщика на чистой системе другого пользователя.

Не заявляем проверенными: установка всех пакетов на чистой Arch VM, полный вход
через DM после публичного установщика, все варианты оборудования, другие дистрибутивы,
а также смена дисплейного менеджера. CI проверяет исходники; он не запускает Hyprland.
