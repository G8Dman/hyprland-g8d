# Проверки v0.2.0-alpha.1

Подготовка: 18 ноября 2026, CachyOS, Hyprland 0.57, Python 3.14 / GTK3.

- Аудит Python/shell/JSON, отсутствие личных файлов, путей автора и токенов в поставке.
- 8 автоматических тестов: выбор версии/контрольная сумма/безопасная распаковка, палитры,
  определение светлой/тёмной темы, независимые мониторы, сохранение цветов, откат при ошибке.
- Установщик с реальным venv/pip в отдельную тестовую домашнюю папку; параметры обычного Hyprland не изменились.
- Сохранены appearance, branding, calendar, cursor-effects, monitors и shortcuts;
  Material-стили и Lua сочетаний сгенерированы под путь установки.
- В локальной сборке проверены все 8 разделов Material You, поиск/пустая выдача, компактная навигация,
  Clear/Graphite, масштаб 200%, редактор цветов (сохранение/повторное чтение/отмена/сброс/валидация).
- Компактное меню: наведением открывается/закрывается, блокируется поверх fullscreen;
  команды радио и запись яркости проверены с изолированными обработчиками, без отключения сети на рабочем ПК.
- Статичные и анимированные обои без звука, отдельные экраны, игровой режим и переподключение проверены локально.

Верификация архива и переход со старого публичного обновлятора выполняются также после публикации,
чтобы проверить доступность настоящих GitHub-адресов. Полные инструкции установки: README.md.

Не проверены: чистая Arch VM, полный вход после перезагрузки на чужом оборудовании, все GPU/мониторы,
полная проверка screen reader. Это предварительный выпуск, а не обещание стабильности на любой системе.

# Проверки alpha.1

Дата подготовки: 14 ноября 2026. Хост: CachyOS, Hyprland 0.57, Python 3.14.

- Разбор Python, проверка shell-синтаксиса и JSON.
- Аудит дерева поставки: нет приватной ссылки календаря, аккаунтов, токенов,
  домашнего пути автора, IP-адресов, резервных копий и схемы его мониторов.
- Реальный запуск установщика в отдельную тестовую домашнюю папку с
  `--no-packages --no-session`: создание Python venv, загрузка зависимостей,
  импорт GTK/Layer Shell, установка файлов и desktop entry.
- Конфигурация принимается `Hyprland --verify-config`.
- Повторная установка: сохранены существующий Hyprland, пользовательские настройки
  календаря, мониторов, акцента и эффектов; резервная копия создана.
- Вложенный запуск публичной конфигурации через `start-hyprland` с Wayland-бэкендом:
  обои, Waybar, hover-триггеры и GTK dashboard появились; ошибок конфигурации нет.
  Тестовая сессия завершена отдельно от рабочего стола пользователя.

Оболочка разработана и использовалась на личном компьютере автора. Это не равно
проверке публичного установщика на чистой системе другого пользователя.

Не заявляем проверенными: установка всех пакетов на чистой Arch VM, полный вход
через DM после публичного установщика, все варианты оборудования, другие дистрибутивы,
а также смена дисплейного менеджера. CI проверяет исходники; он не запускает Hyprland.
